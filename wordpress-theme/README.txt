=== Achados EVOLUWILL - Tema WordPress ===

Tema personalizado para landing page de cupons de desconto
Versão: 1.0
Autor: Willian Tressmann

== INSTALAÇÃO ==

1. Faça o download de todos os arquivos deste tema
2. Crie uma pasta chamada "achados-evoluwill" 
3. Coloque todos os arquivos dentro desta pasta:
   - style.css
   - index.php
   - header.php
   - footer.php
   - functions.php
   
4. Crie uma subpasta chamada "assets" dentro da pasta do tema
5. Coloque a imagem "willian-profile.jpeg" dentro da pasta assets

6. Compacte a pasta "achados-evoluwill" em um arquivo .zip

7. No seu WordPress:
   - Vá em Aparência > Temas
   - Clique em "Adicionar novo"
   - Clique em "Enviar tema"
   - Escolha o arquivo .zip que você criou
   - Clique em "Instalar agora"
   - Após a instalação, clique em "Ativar"

== CONFIGURAÇÃO ==

Após ativar o tema:

1. Vá em Aparência > Personalizar
2. Procure pela seção "Configurações da Landing Page"
3. Cole o link do seu grupo do WhatsApp no campo "Link do Grupo WhatsApp"
4. Personalize a descrição do site se desejar
5. Clique em "Publicar" para salvar as alterações

== PERSONALIZAÇÃO ==

Para alterar o link do WhatsApp:
1. Vá em Aparência > Personalizar
2. Configurações da Landing Page
3. Altere o "Link do Grupo WhatsApp"

Para alterar a foto de perfil:
1. Substitua o arquivo willian-profile.jpeg na pasta assets/
2. Mantenha o mesmo nome do arquivo

Para alterar cores ou estilos:
1. Edite o arquivo style.css
2. As variáveis CSS estão no início do arquivo para fácil customização
